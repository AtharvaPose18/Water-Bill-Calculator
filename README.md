# Water Bill Calculator

A simple Java program that calculates a water bill based on the number of water units consumed. It uses different rates for different consumption ranges.

## Features
- Accepts water consumption as user input
- Calculates the bill using different rate slabs
- Displays the total water bill

## Technologies Used
- Java
- Scanner class
- If-else statements
- Arithmetic operators

## Rate Structure
| Water Units | Rate per Unit |
| First 50 units | ₹1.50 |
| Next 50 units | ₹2.50 |
| Next 100 units | ₹4.00 |
| Above 200 units | ₹6.00 |

## How to Run
1. Download Water_Bill_Calculator.java
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac Water_Bill_Calculator.java
   
4. Run the program:
   java Water_Bill_Calculator
   
## Example Output
Enter water units consumed: 120
Units consumed: 120
Total water bill: Rs. 255.0

## Purpose
This project was created to practise Java basics, user input, conditional statements, and arithmetic calculations.
